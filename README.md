# RME Babyface Pro Interactive Model

A browser-based teaching model inspired by the RME Babyface Pro FS. It illustrates how power, mute, volume, input, and output settings determine a simulated monitoring signal.

Open `index.html` in a modern browser. The model uses HTML, CSS, and JavaScript and runs without installation or a build step.

1. Turn on Power.
2. Choose Mic 1, Mic 2, or Instrument and route it to Speakers or Headphones.
3. Change Monitor volume or toggle Mute. Observe the meters, Current rule, and State changes.
4. Cycle power to see which settings the model retains.

See [TESTING.md](TESTING.md) for the browser test and iteration record.
